# Caché de GeoJSON de uMap

Esta carpeta contiene copias en caché de las capas GeoJSON descargadas de uMap.
Son actualizadas automáticamente por GitHub Action cada 15 minutos.

**IMPORTANTE**: El script `sincronizar.php` usa estos archivos como FALLBACK
cuando uMap bloquea las solicitudes desde Render.com (error 403).

No edites estos archivos manualmente - son generados automáticamente.
